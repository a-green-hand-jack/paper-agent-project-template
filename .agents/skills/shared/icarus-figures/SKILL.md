# Icarus Figures

Turn a dataset + a claim into a **publication-grade figure** — one a top-journal editor accepts with no revision request. Default stack: **matplotlib/seaborn for data figures, original TikZ for hero/method figures**, both reproducible (script + data file), exported as PDF + PNG + SVG.

## First read

Open `references/figure-cookbook.md` and work in this order:

1. **§0b (the quality bar)** — the four axes (Depth · Elegance · Unimpeachable · Visible gap). Internalize this *before* plotting; it is the acceptance test, not an afterthought.
2. **§0a (Figure Contract)** — write the one-line `core_claim` + hero panel + what stats go on the figure, before any code.
3. **§0 style preset** — `from _style import paper_style, save` (the preset lives in `scripts/_style.py`). Never hand-edit rcParams per figure.
4. **§A archetypes A1–A13** — pick the matching template (time series+CI, sorted bar, grouped bar, residual, heatmap, scatter+fit, Pareto, tornado, confusion, phase, network), paste, swap the data path + labels, run.

## For a hero / method / framework figure (the one that carries the paper)

**Read `references/framework-figures.md`** — the deep-dive, with **five** compilable heroes to
paste from (P1 pipeline, P2 paradigm-swimlanes, + T4 graphical-model / data-tensor / matrix-fit),
the borrowable TikZ techniques, and curated journal-grade resources.

The rule to internalize first: **never a generic boxes-and-arrows flowchart** — embed the *real
method object* (a distribution, a before/after scatter, a decision region), not a text label.
Route through the cookbook: **§I** composition paradigms P1–P6 → **§J** craft spec → **§K**
original standalone TikZ (compiled to PDF, `\includegraphics`, zero compile risk). framework-figures.md
walks all three with worked examples.

## Hard rules (non-negotiable)

- **Reproducible only**: every figure is generated by a committed script that reads data from a file path. **No inline data > 20 rows. No AI-generated images** (unreproducible).
- **Three-format vector**: `save()` writes PDF + PNG + SVG (text stays editable in SVG/PDF). Never ship a 72-dpi PNG.
- **Style preset, once**: call `paper_style(...)` at the top; do not tweak rcParams per script.
- **Colorblind + grayscale safe**: use the palette + redundant marker/linestyle so every series survives a B&W print and deuteranopia.
- **Units + N + uncertainty on the figure**: axis labels carry units; N annotated; CI band / error bars shown (§0b axis 3).
- **Acceptance test (run it, don't eyeball it)**: before declaring done, run the gate
  `python scripts/critique.py scripts/figN_<name>.py` — it enforces the §F checklist + §G
  anti-patterns mechanically (must report **no FAIL**) and prints the four judgment prompts.
  Then answer the four §0b axes by hand using `references/figure-critique.md` (the mechanical
  floor is defense; the four judgment ticks are the offense). A figure that merely "plots
  correctly" — or merely passes the script — is not done.

## Optional front-ends / references

- **§M Origin** — allowed only behind the M1–M6 guardrails (same-source CSV, journal .otp template, vector three-format, reproducible matplotlib fallback for key figures). Hero figures never go through Origin.
- **§L external template library** — if `<TEMPLATE_LIB>` is set in `CLAUDE.md`, use it as a *design reference* (imitate composition/palette/chart-type, redraw original); never paste foreign output into the paper.

## Captions

After the figure passes the critique gate (`references/figure-critique.md`), write the caption with `references/caption-and-quality.md` — the caption states the **conclusion**, not "Figure shows X"; reference figures in text as "as in Fig. 3", never "the figure below".

## Output locations

- scripts → `scripts/figN_<short-name>.py` (or `.tex` for TikZ)
- figures → `outputs/figures/figN_<short-name>.{pdf,png,svg}`
- register each in `outputs/figures/figure_manifest.csv` (id, path, claim, source data, generation script).

## In this repository

This section is this template's adaptation. Everything above it is upstream text, unchanged except the front-matter fix recorded in `PROVENANCE.md`.

- **Role.** Reach this skill through `figure-router`. It owns the plotting script and its critique gate; `scipilot-figure-skill` may own chart selection and the publication checks for the same figure, and `thesis-figure-skill` with `tikz-figure-code` own method diagrams.
- **Layout of this copy.** Upstream keeps `SKILL.md` and `references/` under `.claude/skills/icarus-figures/`, and `paperfig/`, `scripts/` and `examples/hero_tikz/` at its repository root. Here all of them sit in `.agents/skills/shared/icarus-figures/`, and every path above is relative to that directory. The `../../../../examples/hero_tikz/X` links in `references/framework-figures.md` mean `examples/hero_tikz/X` in this package, and the `.claude/...` path in `paperfig/__init__.py` means `references/figure-cookbook.md` here.
- **Running it.** From the repository root, set `PYTHONPATH=.agents/skills/shared/icarus-figures` for `from paperfig import paper_style, save`, or `PYTHONPATH=.agents/skills/shared/icarus-figures/scripts` for the `_style` shim; there is no need to install this copy. Install matplotlib and the optional libraries into a project-local environment, for example `uv run --no-project --with matplotlib --with seaborn --with pandas python3 fig.py`, never globally. Run the gate as `python3 .agents/skills/shared/icarus-figures/scripts/critique.py <script> --outdir <dir>`.
- **Output locations.** Instead of `outputs/figures/`, work in `.project/build/figures/<name>/`: point both `save(fig, name, outdir=...)` and `critique.py --outdir` there, then export the file the paper includes to `paper/figures/` (for example `save(fig, name, outdir="paper/figures", formats=("pdf",))`). Instead of `data/processed/*.csv`, read an `assets/<name>` link registered in `assets/MANIFEST.yaml`, or a small data file committed next to the script. Instead of `figure_manifest.csv`, give the figure its entry in `assets/MANIFEST.yaml` (source repository, commit, run, checksum, regeneration command). Keep `figN_<name>.py` in the code repository that produced the data, or next to its output in `paper/figures/`. The paper includes only exported files, so it compiles without `.agents/`.
- **Numbers.** Never type result numbers into a script or a caption; a number quoted in the text goes through an interface macro (`.agents/memory/shared/results-through-interface-macros.md`).
- **Size and legibility.** Beyond the hard rules, the figure fills its allotted area densely at the full column or text width, without large empty margins or sparse panels, and stays legible at fit-page-height on the compiled page, with in-figure text no smaller than the caption text. After the paper build, run the gate in `.agents/memory/shared/post-build-visual-inspection.md`; passing `critique.py` does not replace it.
- **§L external template library.** `<TEMPLATE_LIB>` is not set in this repository; skip §L unless the Human names a library.
- **Boundary.** A change that touches a `locked` item in `PAPER.md` goes to `control-review` first.

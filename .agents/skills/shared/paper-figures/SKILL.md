# Paper figures

Identify the claim, source data and intended publication form. For quantitative figures use a reproducible script and registered data; for diagrams preserve the supported topology and labels in an editable source. Select tools for the task, rather than running every available workflow. Inspect the figure at its final size in the built paper.

- [Figure workflow](sources/scientific-figure-workflow/reference.md)
- [Chart selection and visual checks](sources/scipilot-figure-skill/reference.md)
- [Plotting tools and critique](sources/icarus-figures/reference.md)
- [Method diagrams](sources/thesis-figure-skill/reference.md) and [TikZ correctness](sources/tikz-figure-code/reference.md)
- [Reconstruct editable presentations](sources/image-to-editable-ppt/reference.md)

Conceptual figures are drawn as slides and exported with a project script
([`figure-deck-and-export`](../../../memory/shared/paper-figures/figure-deck-and-export.md)).

A writing or design exemplar is not evidence for the figure's claim. Review changes to locked claims or interfaces before altering them.

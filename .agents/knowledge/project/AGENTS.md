# Project knowledge rules and index

This directory contains dated facts owned by this repository. Every record is a
separate Markdown file with the fields in
[`../ENTRY_TEMPLATE.md`](../ENTRY_TEMPLATE.md), `scope: project`, and a refresh
or expiry condition. A paper keeps facts here that only it needs, such as a
workshop's rules or a venue record specific to its track.
